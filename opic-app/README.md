# OPIc 말하기 연습 앱 (opic-app)

휴대폰 세로 화면용 OPIc 영어 말하기 연습 앱입니다. 서버·계정·유료 API 없이 브라우저만으로 동작하고, 녹음과 기록은 기기의 IndexedDB에 저장합니다. 저장소 루트의 기존 시뮬레이터(`../index.html`)는 그대로 두고, 그 코드와 문제은행을 가져와 이 폴더에 새로 만들었습니다.

## 실행

마이크와 오프라인 실행은 **https://** 또는 **localhost**에서만 동작합니다. 파일을 직접 열면(`file://`) 화면은 열리지만 녹음·설치·오프라인 실행은 안 될 수 있고, 앱이 상단에 안내를 띄웁니다.

```bash
# 저장소 루트에서
cd opic-app
python3 -m http.server 8000
# PC 브라우저: http://localhost:8000
```

휴대폰에서 바로 쓰려면 아래 GitHub Pages로 배포한 https 주소를 여세요. 같은 Wi-Fi의 `http://192.168.x.x:8000`은 https가 아니라서 휴대폰 브라우저가 마이크를 막습니다.

설치: 아이폰 Safari는 공유 → 「홈 화면에 추가」, 갤럭시 Chrome은 메뉴(⋮) → 「앱 설치」 또는 「홈 화면에 추가」.

## GitHub Pages 배포 (opic-app 폴더만)

`.github/workflows/opic-app-pages.yml`이 `opic-app/`만 골라 배포합니다(`tests/` 폴더는 제외, 서비스 워커 캐시 버전은 커밋 해시로 자동 교체).

1. 이 브랜치를 `main`에 합칩니다 (워크플로는 `main`에 push될 때 실행되고, Actions 탭에서 직접 실행도 할 수 있습니다).
2. GitHub 저장소 → **Settings → Pages → Build and deployment → Source: GitHub Actions** 를 고릅니다.
3. **Actions** 탭에서 「Deploy opic-app to GitHub Pages」가 끝나면 `https://<사용자명>.github.io/<저장소명>/` 에서 열립니다.

다른 브랜치나 `dojo-dog/` 같은 다른 폴더는 배포 대상에 들어가지 않습니다.

## 테스트

node --test opic-app/tests/unit.test.js   # 분석·문제 선택·퀴즈·백업 검증 등 순수 로직

## 문제은행

- **313문항 · 70개 주제** (설문 주제 41 · 돌발 16 · 롤플레이 세트 11 · 공통 2)
- 유형: 자기소개 2 / 묘사 71 / 습관·루틴 55 / 과거 경험 87 / 비교 46 / 롤플레이(질문하기) 14 / 롤플레이(문제 해결) 10 / 이슈 28
- 분류: 설문 주제 200 / 돌발 주제 65 / 롤플레이 34 / 공통 14
- 난이도: 기본 134 / 중간 127 / 고난도 52
- 기존 시뮬레이터에서 다듬어 가져온 문항 149개, 새로 쓴 문항 164개(관점 바꾸기용 11개 포함)

기존 문제은행 정리 내역:
- 중복 제거: 마무리 콤보(FINALS)의 '쉬운 질문'(친구·주말)과 '비슷한 질문'의 건강 이슈가 난이도별 콤보와 똑같아 하나로 합침. 환경 이슈 중복도 합침.
- 유형 태그 수정: 음악 '과거 경험' → 실제로는 비교 질문, 인터넷 '습관' → 과거 경험, 은행 '습관'(두 질문이 섞여 있음) → 습관 + 과거 경험으로 분리, 콘서트 '묘사'(지난 콘서트 이야기) → 과거 경험.
- 어색한 영어: `Why do you like him or her, and what movies has he or she been in?` → `What movies have they been in, and why do you like them?` 등 he or she 반복 정리, 롤플레이 도입부를 `I'd like to…`/`I'm sorry, but…`로 자연스럽게, 지나치게 긴 질문 일부 축약.
- 설문에 있지만 문제가 없던 주제 추가: 술집/바, 집에서 보내는 휴가(기존 기본 세트에 들어 있었는데 문제가 없었음), 박물관, 스포츠 관람, 뉴스, 드라이브, 악기, 노래, 춤, 글쓰기, 그림, 반려동물, 요가, 자전거, 구기 운동, 출장, 학교·일.
- 부족한 유형 보강: 롤플레이 세트 4 → 11개(+ 면접관에게 질문하기), 비교·이슈 질문, 돌발 주제(음식, 동네, 가전, 건강, 가족·친구, 주말, 지형, 약속).
- 기존 샘플 문제(오늘 날씨)는 연습 효과가 적어 제외.

출제 규칙: 최근에 나온 질문은 뒤로 미뤄 반복 출제를 피하고, 사용자가 ★(복습 지정)한 질문은 우선 다시 출제합니다.

## 알아 둘 점

- 자동 분석은 **규칙 기반 참고값**입니다. 단어 수·연결어 개수로 등급을 판단하지 않고, 점수도 보여 주지 않습니다.
- 등급 체크리스트는 ACTFL 말하기 지침의 등급 설명을 참고한 **연습용 기준**이며 공식 채점이 아닙니다.
- 아이폰 Safari는 오래 쓰지 않은 사이트의 데이터를 지울 수 있습니다. 홈 화면에 설치해서 쓰고, 「기록 → 백업」으로 주기적으로 내보내세요(앱이 7일마다 알려 줌).
- 다른 기기에서 녹음한 webm 파일은 아이폰에서 재생이 안 될 수 있습니다. 이때는 「오디오 내보내기」로 저장해 다른 앱에서 들으세요.
- 앱을 고친 뒤 직접 배포할 때는 `sw.js`의 `VERSION`을 바꿔야 휴대폰에 새 버전이 적용됩니다(위 워크플로는 자동 처리).
