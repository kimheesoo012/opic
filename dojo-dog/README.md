# 道場犬 (dojo-dog)

일본 동네 검도장에 사는 닥스훈트의 견생 시뮬레이션. 휴대폰 세로 화면용 웹 게임(PWA).
개는 검도를 하지 않는다. 도장에서 살며 사람들의 인생을 지켜보고, 작은 행동으로 조금씩 바꾼다.

- 목적: JLPT N2 공부. 대사 속 어려운 문법·단어가 장면마다 최대 3개(학습 집중 모드는 6개) 밑줄로 표시된다(문법은 물결 밑줄). 번역은 기본으로 숨기고, 탭해야 창이 열린다
- 해설·선택지: 한국어 / 사람들의 대사: 일본어 (탭 → 뜻·품사·게임 속 문장·관련 표현, 「단어장 저장」)
- 「復習」: 오늘 복습할 단어·문법, 최근 틀린 항목, 어려운 항목. 문제는 일→한 뜻, 한→일 단어, 읽기(함정이 3개 이상 있을 때만), 장면 속 뜻, 문법 빈칸·문법 구별. 1·3·7·14일 간격. 시작 전 「今日の一問」
- 장면은 일본어가 먼저다: 한국어 해설은 상황 한두 문장(40자 안팎)만 보이고 나머지는 「더보기」. 대사 아래에 「번역」.
- 선택지(설정 → 선택지): 기본 「중요한 장면만」. 나머지 장면에서는 개가 성격대로 움직이고 つぎへ만 누른다(「직접 고르기」로 언제든 고를 수 있다). 직접 고르는 장면도 「행동 고르기」를 누른 뒤에 선택지가 펼쳐져 대사를 가리지 않는다.
- 도트 창은 개를 따라가는 2배 카메라로 보인다(시합·심판 장면은 전체 화면).
- 플레이 중 학습(설정 → 모드):
  - 학습 모드(기본): 4~5장면마다 확인 문제 1개(설정에서 끄기/적게/보통/많이), 계절이 바뀔 때 가끔 복습 카드. 문제는 장면이 끝난 뒤에만 나오고, 답하는 동안 시간이 멈춘다. 「건너뛰기」 가능.
  - 감상 모드: 퀴즈·복습 카드가 저절로 나오지 않는다. 「復習」 메뉴는 그대로.
  - 유형: 문장 속 뜻(단어·문법), 게임 대사의 문법 빈칸, 비슷한 표현 구별, 뜻 고르기, 일본어 고르기, 읽기.
  - 틀린 말은 다른 문제를 두 개 이상 지난 뒤 다른 유형으로 다시 나오고(한 견생에 두 번까지), 간격 반복에서 다음 날 복습으로 돌아온다. 이번 견생에서 맞힌 말은 다시 내지 않는다.
  - 빈칸 문제의 오답은 대사를 읽고 사람이 고른 목록(`BLANK_SET`)만 쓰고, 뜻이 가까운 문법은 서로 오답으로 쓰지 않는다(`NEAR`).
  - 견생이 끝나면 「この一生の日本語」: 만난 N2 어휘·문법, 퀴즈 정답률, 취약 표현, 다음 복습 예정.
  - `node tools/quizsim.mjs 40 all`: 40판 시뮬레이션(빈도별 퀴즈 수·중복 출제율·오답 재출제율). `node tools/quiz-flow.mjs`: 화면 확인.
- 게임 능력치(개의 상태·관계)와 일본어 학습 기록은 따로 센다. 퀴즈를 틀려도 능력치·이야기에는 영향이 없다. 복습을 해도 개가 강해지지 않는다
- 한 판: 오토 1배속 약 17~24분(평균 19분, 모델 기준), 16배속 약 1분 반
- 서버 없음. 저장은 브라우저 localStorage

| `src/data/` | 이벤트(일상·검도·서브스토리·委員長·식구 서사·고비), 어휘 DB, 칭호, 마지막 인사 |
| `src/gen/lines.json` | 빌드 도구가 만든 대사 조각(후리가나·학습 단어). 데이터를 고치면 다시 생성 |
| `src/engine/study.js` | 간격 반복 기록, 복습 문제 생성(읽기 함정·뜻·단어·장면 속 뜻·문법 빈칸·문법 구별), 학습 통계 |
| `src/engine/learn.js` | 후리가나 모드·학습 수준·학습 대상 고르기 |
| `src/engine/quizplan.js` | 플레이 중 확인 문제·복습 카드의 시점·항목·유형, 견생 정리 |
| `src/data/chains.js` | 개의 행동이 이어지는 연작(슬리퍼, 장부, 신입, 비옷, 호구 가방, 委員長 10·11화 등) |
| `src/data/grammar.js` | 문법 DB (형태·뜻·접속·차이·빈칸 문제·해설) |
| `src/ui/pixel/` | 도트 그림. 팔레트·버퍼 `core.js`, 닥스훈트 `dog.js`, 사람 `people.js`, 배경 `bg.js`, 장면 연출 `director.js`, LCD 창 `lcd.js` |
| `src/ui/` | 화면, 결과 카드, 복습 화면, Web Audio 소리 |
| `tools/` | 대사 조각 생성기, 빌드, 아이콘, 브라우저 E2E, 도트 시트(`sheet.mjs`), 화면 캡처(`shots.mjs`) |
| `test/` | 자동 테스트 (시드 320개 오토 시뮬레이션 등) |

## 명령

```bash
npm install
npm run ruby     # 대사 데이터를 고친 뒤: 후리가나·학습 단어 조각 다시 생성 (kuromoji, 빌드 때만 사용)
npm test         # 자동 테스트
npm run build    # dist/pwa (PWA 정적 파일), dist/artifact/dojo-dog.html (단일 파일), dist/dojo-dog-pwa.zip
# 브라우저 E2E: dist/pwa 를 정적 서버로 띄운 뒤
python3 -m http.server 8765 --directory dist/pwa &
npm run e2e -- http://localhost:8765/
node tools/sheet.mjs dog|people|bg|scene   # 도트 시트 PNG → tools/out/
node tools/read-flow.mjs http://localhost:8765/ 375 548 s0,k3   # 읽기 흐름 화면 확인 → tools/out/flow/
```

## 대사 속 학습 표시

- `[표기|사전형]` 단어, `〘표면|문법키〙` 문법, `{N}` 등 자리표시자, `〔한자:읽기〕` 읽기 고정
- 어휘 DB에 N2(추정)로 있는 말은 표시하지 않아도 생성기가 자동으로 잇는다
- 생성기는 후리가나 조각마다 수준 코드(`5`~`1` JLPT 추정, `K` 검도 용어, `P` 고유명사)를 붙인다

## 설정 → 일본어

| 항목 | 선택 | 기본값 |
|---|---|---|
| 후리가나 | 항상 / N2 이상 어휘만 / 어려운 한자·고유명사만 / 끄기 | 항상 (처음 하는 사람이 막히지 않게. 익숙해지면 설정에서 「N2 이상 어휘만」으로) |
| 학습 수준 | N5~N4 / N3 / N2 / N1 / 직접 선택(N5~N1·검도 용어 체크) | N2 |
| 쉬운 단어 학습 표시 끄기 | 켜면 학습 수준보다 쉬운 말은 밑줄을 긋지 않는다(단어 자체는 그대로) | 켬 |
| 학습 집중 모드 | 학습 표시 늘림, 장면별 학습 칩, 줄마다 「번역」, 오토 속도 느림 | 끔 |

- 후리가나와 학습 수준은 따로 움직인다. 게임 도중 바꾸면 지금 장면이 바로 다시 그려진다.
- 사람 이름 등 고유명사는 처음 나올 때 읽기를 달고, 그 뒤로는 후리가나 설정을 따른다. 이름을 탭하면 읽기가 보인다.
- 후리가나·학습 밑줄·고유명사 표시는 서로 다른 규칙으로 정한다: 후리가나는 「설정 × 낱말 수준」만, 밑줄은 장면의 학습 대상만(단어 실선·문법 물결선), 고유명사는 점선이고 처음 나올 때만 읽기를 단다.
- 사전에 없는 낱말의 수준은 `src/data/word_levels.js`(일상어 목록) → 한자 추정 순서로 정한다. 생성기를 돌리면 `tools/out/levels.txt`(낱말별 수준), `tools/out/conn.txt`(문법이 붙은 말), `tools/out/ruby-review.txt`(읽기 전부)로 검토할 수 있다.
- 문법 창의 「이 문장의 접속」은 생성기가 형태소로 만들고, 틀리기 쉬운 곳은 `tools/gen-lines.mjs`의 `CONN_FIX`에 직접 적었다.
- 예전 설정(`furigana: 'hard'` 등)은 처음 불러올 때 새 설정으로 옮긴다(`migrateSettings`). 단어장·복습 기록·세계 기록은 그대로 읽는다.

## 홈 화면 앱(PWA)으로 쓰기

`dist/dojo-dog-pwa.zip`의 내용을 HTTPS 정적 호스팅(GitHub Pages, Netlify 등)에 올리고 그 주소를 휴대폰으로 연다.

- iPhone(Safari): 공유 버튼 → 「홈 화면에 추가」
- Android(Chrome): 메뉴 → 「앱 설치」 또는 「홈 화면에 추가」

한 번 열고 나면 서비스 워커가 파일을 저장해 두어서 비행기 모드에서도 실행된다.

같은 도메인에 다른 사이트가 있다면(GitHub Pages의 `https://<user>.github.io/<repo>/` 등) 도장견은 전용 폴더(예: `/<repo>/dojo-dog/`)에 올린다.
서비스 워커는 자기 폴더를 범위(scope)로 등록되고, 캐시 이름은 `dojoinu-<버전>`이며, 응답도 이 캐시에서만 꺼낸다. 오래된 캐시를 지울 때도 `dojoinu-`로 시작하는 것만 지운다.
`file://`로 직접 열면 서비스 워커가 동작하지 않으므로 오프라인 설치는 되지 않는다(게임 자체는 실행된다).

## 일본어와 어휘

- 대사의 후리가나는 빌드 때 형태소 분석(kuromoji)으로 만들고, 수사·검도 용어 등 틀리기 쉬운 읽기는 `tools/gen-lines.mjs`의 사전으로 고정했다.
- 학습 단어는 어휘 DB(`src/data/vocab_*.js`)에 있는 말만 밑줄이 그어진다. 탭하면 이 DB의 읽기·뜻·예문만 보여 준다.
- JLPT 수준은 공식 목록이 없어서 전부 「추정」이다(N2 추정 / N3 추정). 검도 전문어는 「검도 용어」로 표시한다.
- 문법 수준은 공개 학습 사이트의 N2/N3 문법 목록에서 흔히 쓰이는 분류를 따라 N2 추정·N3 추정으로 나눴다. 사이트마다 분류가 다르고(예: ～わけにはいかない, ～につれて) 공식 목록이 아니므로 참고용이다.
- 검도 규정(段 응시 조건, 형 본수, 심판 3명과 깃발, 반칙 2회=상대 一本 등)은 처음 만들 때 웹 검색 결과(연맹 요강 해설 등)를 참고했다. 이후 개선 작업에서는 외부 사이트에 접속할 수 없어 稽古·礼·正座·切り返し·掛かり稽古·地稽古·残心·昇段審査·寒稽古·錬成会·有効打突의 쓰임은 일반 지식으로만 다시 검토했다. 실제 응시 전에는 소속 연맹의 최신 요강을 확인할 것.
- 한국어 해설에서는 검도 용어를 한국어로 옮기거나(연습, 호구, 죽도, 한 판), 한국어로 옮기기 어려운 말만 일본어로 남기고 탭하면 설명이 나오게 했다.
