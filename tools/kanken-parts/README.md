# 漢検 위젯 부품 데이터

- `kanji_parts.jsonl`: 한 줄에 한자 하나 (6,670자). `grep -m1 '^{"k":"語"'`로 한 줄만 읽으면 된다.
  - `k` 한자, `ko` 한국어 훈음, `ord` 「부품 먼저」 순서(상용한자 2,136자만, 1부터), `in`/`inN` 이 한자를 부품으로 쓰는 상용한자(앞 20자)/전체 수
  - `parts[]`: `c` 부품, `ko` 훈음·부수 이름, `pos` 자리(왼쪽·오른쪽·위·아래·받침·엄·둘레…), `rad` 부수면 1, `orig` 원래 모양, `in`/`inN` 그 부품이 들어간 상용한자(앞 14자)/전체 수, `sub` 더 작은 부품
- `preview.html`(+ `preview_data.json`): 정답 화면에 넣을 부품 패널 디자인 미리보기. `__DATA__` 자리에 preview_data.json 내용을 넣으면 열린다.
- 만든 방법: KanjiVG(CC BY-SA 3.0) 부품 분해 + libhangul 한자 사전 훈음 + OpenCC 신자체 표 + kanji-data(급수·빈도). `b2.py` → `b3.py`, 부품 이름 직접 정리는 `names.py`.

## 위젯에 붙일 것
1. 정답 확인 뒤 화면에 부품 패널: 맨 위 「言 + 義 = 議」 큰 식, 부품마다 카드(큰 글자·훈음·자리·부수·원래 모양·더 작은 부품), 카드 아래 「그 부품이 들어간 한자」 칩(누르면 그 한자로 이동), 맨 아래 「이 한자를 부품으로 쓰는 한자」.
2. 출제 순서에 「부품 먼저」(ord 오름차순) 추가.
3. 위젯에 안내 문구는 넣지 않는다.
