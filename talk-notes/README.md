# 회화 교정 노트 (talk-notes)

영어 회화 수업 교정 노트(「영어 회화 교정 노트」 HTML)를 그대로 담고, 그 문장으로 말하기·빈칸·발음을 연습하는 휴대폰 앱입니다. 서버·계정·유료 API 없이 정적 파일로만 동작하고, 기록은 기기 브라우저에 저장됩니다.

- 주소(main에 병합 후): `https://kimheesoo012.github.io/opic/talk-notes/` → 휴대폰에서 열고 「홈 화면에 추가」
- 로컬: 저장소 루트에서 `python3 -m http.server 8000` → `http://localhost:8000/talk-notes/`
  (ES 모듈이라 파일을 직접 열면 동작하지 않습니다. 마이크·음성 인식은 https 또는 localhost에서만 됩니다.)

## 담은 내용 (원본 노트 전부)

| 원본 노트 | 앱 |
|---|---|
| 수업 10회(8/7~10/28), 문장 633개: 상황·원문·수정·해석·설명·더 자연스럽게·실수 태그 | 노트 → 수업별 문장 (수업·실수 유형 필터, 해석/자연스러운 표현 가리기), 검색, 별표, 문장마다 메모 |
| 반복되는 실수 11가지 + 수업별 비율 막대 + 예문 | 노트 → 반복되는 실수 (+ 내 연습 정답률, 바로 연습 버튼) |
| 좋아진 점 12가지 | 노트 → 좋아진 점 |
| 발음 체크 표 3개(36단어) | 노트 → 발음 체크 (+ 듣기, 내 결과) |
| 바로 쓸 표현 6묶음(36개) | 노트 → 바로 쓸 표현 (+ 듣기) |

데이터는 `js/data/notes.js` 하나입니다. 노트가 새 수업으로 갱신되면 `node talk-notes/tools/import-note.cjs <노트.html> talk-notes/js/data/notes.js`로 다시 만들 수 있습니다(같은 형식일 때).

## 연습 8가지

| 모드 | 하는 일 | 채점 |
|---|---|---|
| 🎙 말하기 카드 | 상황 + 한국어 뜻 → 영어로 말하기. 힌트(조심할 실수 유형·첫 단어) | 음성 인식 결과를 수정문·자연스러운 표현과 단어 단위로 비교(빠진 말·더한 말 표시) → 추천 평가, 최종 평가는 직접 |
| 🧩 고친 부분 빈칸 | 수정문에서 고쳐진 말만 빈칸. 보기에 그때 내가 한 말(함정)이 섞임 | 자동 |
| ⭕ 맞는 문장? 틀린 문장? | 수업 원문 또는 수정문을 보고 O/X | 자동 |
| 🔁 듣고 따라 말하기 | 자연스러운 표현을 듣고 따라 말하기(문장 가리기, 천천히) | 음성 인식 비교 → 추천 평가 |
| 👄 발음 체크 | 녹취에서 잘못 인식된 단어(rice→lice 등)를 말하고 제대로 인식되는지 확인, 3번까지 | 자동 (인식 후보 5개 중 목표 단어 포함 여부) |
| 👂 소리 구분 듣기 | rice/lice, walk/work 등 23짝 중 어느 쪽을 읽었는지 | 자동 |
| 💬 바로 쓸 표현 | 한국어 → 영어 표현 떠올리기 | 음성 인식 비교 → 추천 평가 |
| 🚩 실수 패턴 퀴즈 | 반복되는 실수 예문 48개에서 맞는 쪽 고르기 | 자동 |

- **오늘의 학습**: 오늘 복습할 모든 종류 + 새 말하기 카드(하루 개수 설정) + 이미 말해 본 문장의 빈칸·O/X 변형 + 가끔 표현·소리 구분·패턴을 섞어 한 번에 20문제(설정).
- 모드별로 범위(수업·실수 유형·별표)·순서(복습 먼저/안 푼 것만/자주 틀린 것/무작위/노트 순서)·문제 수를 고를 수 있습니다.
- 「다시」로 평가한 문제는 세션 끝에 한 번 더 나오고, 끝나면 틀린 문제만 다시 풀 수 있습니다. 중간에 나가도 「이어서 하기」.
- 간격 반복: SM-2를 단순화(다시 → 오늘, 알맞음 → 1일 → 3일 → 약 7일 …). 21일 넘게 기억하면 「익힘」. 하루는 새벽 4시에 바뀝니다.
- 새 문장은 기본으로 최근 수업부터 나오고, 수업 때도 맞게 말한 짧은 문장은 뒤로 미룹니다.
- 음성 인식이 안 되는 브라우저·오프라인에서는 직접 입력하거나 「말했어요 · 정답 보기」로 스스로 평가합니다. 「내 목소리 녹음」을 켜면 답을 녹음해 정답 소리와 비교해 들을 수 있습니다(문제마다 마지막 녹음 1개, IndexedDB).

## 매일 하게 만드는 장치

- **XP·레벨**: 문제마다 2~12 XP(다시 2 · 어려움 5 · 알맞음 10 · 쉬움 12), 새 문장 +4, 3연속 정답부터 +3, 오늘 첫 문제 +10, 하루 목표 달성 +30. 레벨 L→L+1에 50·L·(L+1) XP가 필요해서 하루 20문제면 첫날 2레벨, 닷새째 5레벨, 한 달쯤 10레벨. 레벨마다 칭호(새싹 → 수강생 → 말문 트임 → 스몰토커 → 수다쟁이 → 대화 선수 → 네이티브 느낌 → 회화 마스터).
- **연속 학습일**: 하루 1문제라도 풀면 이어져요. 홈 화면 첫 줄에 오늘 상태(「오늘 안 풀면 끊겨요」 등)를 보여 주고, 3·7·14·30·60·100일마다 배지.
- **휴식권 🧊**: 7일 연속마다 1장(최대 2장). 하루 빼먹으면 다음 날 첫 문제를 풀 때 자동으로 써서 연속을 지켜요.
- **배지 24개**: 첫걸음, 목표 달성 횟수, 연속일, 말해 본 문장 수, 익힌 문장 수, 수업 완주·정복, 발음, 약점 극복(한 유형 정답률 85%), 10연속 정답, 레벨, 백업 등.
- **실력이 보이게**: 실수 유형별 **숙련도 0~100%**(그 유형 문장을 얼마나 오래 기억하는지: 처음 0 · 익히는 중 35 · 복습 중 70 · 익힘 100의 평균), 전체 숙련도, 30일 익힌 문장 수 추이 그래프, 14일 XP 막대, 이번 주 막대(목표 달성일은 초록).
- **세션 끝 화면**: 얻은 XP, 레벨 진행, 연속일과 다음 단계까지 남은 날, 새 배지, 목표까지 남은 문제 → 바로 이어서.
- **매일 알림**: 설정에서 시각을 고르면 매일 반복 일정(.ics)을 내려받아 휴대폰 캘린더에 넣을 수 있어요. 앱 자체는 서버가 없어 푸시 알림을 보낼 수 없어요.

## 기록·설정

- 기록: 푼 문제·정답률·연속 학습일·연습 시간, 최근 30일 달력, 문장 진도(처음/익히는 중/복습 중/익힘)와 수업별 진도, 실수 유형별 정답률, 연습 종류별 정답률, 앞으로 7일 복습량, 자주 틀린 문제(바로 다시 풀기), 발음 단어별 성공률.
- 설정: 테마(기기/밝게/어둡게), 읽어 주는 목소리·속도, 음성 인식·녹음·자동 읽기·효과음, 하루 새 문장·한 번에 푸는 문제·하루 목표·새 문장 순서, 백업 내보내기/가져오기(형식이 틀린 파일은 기존 기록 유지), 초기화.

## 파일

```
talk-notes/
  index.html, manifest.webmanifest, sw.js, icons/
  css/app.css
  js/app.js                 해시 라우터
  js/data/notes.js          원본 노트 데이터
  js/core/text.js           문장 비교(LCS)·빈칸 만들기·발음 확인
  js/core/srs.js            간격 반복
  js/core/game.js           XP·레벨·연속(휴식권)·배지·숙련도
  js/core/deck.js           문제 목록·세션 만들기
  js/core/store.js          기록(localStorage)·녹음(IndexedDB)·백업
  js/core/speech.js         읽어 주기·음성 인식·녹음
  js/ui/                    화면 (home, note, practice, session, items, card, stats, settings, ui)
  tools/                    import-note.cjs(노트 → 데이터), build-sw.cjs(오프라인 목록), icons.cjs
  tests/                    unit.test.mjs, e2e.cjs
```

앱 파일을 고친 뒤에는 `node talk-notes/tools/build-sw.cjs`로 `sw.js`를 다시 만들어 함께 커밋해야 휴대폰에 새 버전이 적용됩니다(CI가 확인).

## 테스트

```bash
node --test talk-notes/tests/unit.test.mjs   # 원본 내용 개수, 문장 비교, 빈칸(모든 빈칸 문제가 수정문으로 복원되는지), 간격 반복, 세션,
                                             # XP·레벨, 연속·휴식권, 숙련도·배지·성장 그래프
node talk-notes/tests/e2e.cjs                # 390×844·375×667 Chromium: 모든 화면 가로 넘침, 노트 필터·별표·검색,
                                             # 오늘의 학습 한 바퀴, 이어서 하기, 발음 성공/실패, 빈칸, 메모, 테마, 백업
```

e2e는 헤드리스 브라우저에 마이크가 없어 음성 인식·읽어 주기를 가짜로 바꿔 돌립니다. 실제 아이폰 Safari·갤럭시 Chrome에서 마이크로 해 보는 확인은 하지 않았습니다.

## 알아 둘 점

- 자동 채점은 단어 일치 비교라 참고용입니다. 뜻이 같은 다른 표현도 낮게 나올 수 있어서 말하기 종류는 최종 평가를 직접 고르게 했습니다.
- Chrome 음성 인식은 인터넷이 필요하고 음성이 Google 서버로 전송됩니다. 아이폰 Safari는 기기 설정의 Siri·받아쓰기가 켜져 있어야 할 수 있습니다.
- 아이폰은 오래 안 쓴 사이트 데이터를 지울 수 있어서, 기록이 쌓이면 일주일마다 백업을 알려 줍니다.
